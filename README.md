# 净屏 1.1.8

免 Root 的 Android 广告处理工具，重点适配红果短剧、红果漫剧和番茄短剧。

1.1.8 不再依赖“黑屏上滑猜下一集”，改为四层处理：

1. 用仅作用于重点应用的本地 VPN 透明代理拦截已知广告请求。
2. 用无障碍服务处理开屏跳过、短剧广告页和摇一摇误跳。
3. 对漏网的剧集插页广告，返回历史页后用播放器“选集”精确定位到第 N+1 集，从该集开头播放。
4. 识别红果播放器内的金币红包挂件，走 App 自带暂停态 X 和永久关闭确认，不点“立即领取”或“仅今日关闭”。

已在 **iQOO Z10 Turbo Pro（V2453A / Android 16 / 系统 PD2453D_A_16.1.18.1.W10）** 上实测。

## 工作方式

- `VpnService` 只把已勾选的重点应用流量送入本机 TUN，其他 App 直接联网；切换重点应用后会自动重启过滤范围。
- `tun2socks` 把 TUN 流量交给 App 内部的 SOCKS5 服务。
- SOCKS5 只监听 `127.0.0.1`，所有上游 socket 都先调用 `protect()` 并绑定当前 Wi-Fi/蜂窝网络。
- 不连接第三方 VPN 或代理；普通 DNS 查询按当前网络的系统解析器或公开解析器正常转发。
- DNS 查询命中广告域名时返回失败。
- 对 HTTPDNS 或 IP 直连连接，再检查 TLS ClientHello 的 SNI / HTTP `Host`；命中规则时直接断开。
- 普通 HTTPS 内容不会被解密，也不会上传或保存。
- 广告出现时，用最近 120 秒内实际访问过的域名做关联学习；高置信广告标签自动加入屏蔽，疑似追踪域名进入待确认列表。

## 已实现

- 点击开屏广告里的“跳过”“跳过广告”“关闭广告”等明确按钮。
- 剧集广告“秒退”：识别带广告标记的倒计时或无倒计时插页后立即返回，自动处理“下次再说”收藏弹窗，再按剧名匹配历史记录。
- 重进播放器后打开“选集”，直接点击第 N+1 集；不再用不可见的播放进度猜测，也不需要盲上滑。
- 精确选集从下一集片头开始，避免倒计时结束后的黑屏期间已经偷播、导致下一集开头缺失。
- 整个恢复过程使用分阶段状态机和 5.2 秒广告转场锁；即使新页面又出现广告，也不会在几秒内连续翻两页。
- 红果播放器内的“立即领取”“听读赚钱”“6500金币”等右侧浮层会被识别为金币红包挂件。
- 播放态没有 X 时，会短暂暂停视频露出 App 原生关闭按钮；点击 X 后只选择“关闭”或“隐藏”，遇到“仅今日关闭/隐藏”会主动避开。
- 关闭成功后自动恢复播放，并进入冷却，不会反复暂停、误点领取或跳进福利页。
- 当前剧名和集数保存在本机；播放器剧名改为直接按界面节点识别，不再依赖可能为空的 Activity 类名。
- 空白广告容器只有在“同一稳定集数持续黑屏 5 秒且没有发生广告转场”时才允许一次兜底上滑，避免把正常加载误判成广告。
- 秒退只信任最近 2 分钟内实际读取到的剧名，避免把上一季剧名误用到当前剧集。
- 自动翻页后加防重复锁，广告标记消失前不会连续翻两页。
- 识别无触摸情况下跳到微信、浏览器、应用商店等页面的“摇一摇误跳”，自动按返回。
- 可给漏网广告添加自定义域名，立即生效。
- 自动学习到的广告域名保存在本机，下一次请求立即按已学习规则阻断；待确认域名可在学习记录里手动屏蔽。
- 默认只对以下应用使用剧集强规则，可单独关闭：
  - `com.phoenix.read` 红果短剧
  - `com.kylin.read` 红果漫剧
  - `com.dragon.read` 番茄小说 / 短剧
- 可开启“所有 App 的开屏广告”，对其他应用只点击非常明确的“跳过广告”类按钮。
- 所有统计只保存在本机。

## 免 Root 的边界

Android 上无法用普通第三方 App 保证“所有 App、所有广告、绝对为零”，本项目也做不到：

1. 广告请求与业务共用域名、使用 DoH/QUIC、TLS 中不带可识别 SNI，或规则库尚未收录时，仍可能漏过。
2. 强制倒计时仍受目标 App 控制；倒计时结束前通常不能滑动跳过，本工具只会在倒计时结束后自动点“跳过/关闭”或上滑，无法篡改计时器。
3. 红果剧集“秒退 + 精确选集”是通过返回历史页、重进播放器并从内置选集中选择下一集实现，不是缩短目标 App 的计时器；部分版本界面结构变化后可能失效。
4. 视频画面里已经烧录的植入广告、剧内口播和道具广告不是独立网络请求或界面节点，无法移除。
5. Android 16 没有按应用关闭加速度传感器的一般接口，因此“摇一摇”只能在检测到无触摸外跳后返回。
6. 金币红包挂件依赖目标 App 暴露的原生 X/关闭确认；如果红果后续版本删除该入口或更换界面，需要重新适配。
7. 本地转发会增加目标应用少量耗电和首包延迟；非重点应用不经过该 VPN。
8. 自动学习只能关联“广告出现前不久刚访问过”的域名；与业务共用域名、在广告出现前早已建立连接或使用加密 DNS 的请求仍可能漏过。

要做到代码层彻底删除广告、传感器监听和强制倒计时，仍需要 Root/LSPosed、修改目标 APK，或使用官方无广告版本。

## 安装

```bash
adb install -r dist/jingping-v1.1.8-debug.apk
```

当前 APK：`dist/jingping-v1.1.8-debug.apk`  
SHA-256：`7dc3ea5dad0c2ded282d456b31422e0890b627cad3f61c3745a2a8b310a0e48c`

如果 vivo 弹出外部来源安装确认，按系统提示继续。

安装后：

1. 打开“净屏”。
2. 点“立即开启”，在系统无障碍设置中启用“净屏 · 本地广告过滤”。
3. 在下方点“开启本地过滤”，授权系统 VPN。
4. 保持“自动跳过广告”“广告秒退 · 精确选集”“关闭金币 / 红包挂件”“摇一摇误跳自动返回”开启。

“广告秒退 · 精确选集”会短暂切到历史页，再通过播放器选集直接播放下一集片头。如果某一版红果界面结构变化导致无法恢复，可关闭该开关，退回“遮挡广告画面”的兼容模式。

## 隐私

- App 本身不运营服务器，不上传界面内容、截图、账号信息或广告拦截记录。
- 普通流量只在本机 SOCKS5 中转，不解密 HTTPS，不保存请求正文。
- 本机只保存阻断次数、查询次数、最近一次域名、自动学习/待确认域名、处理次数，以及用于秒退续播的当前剧名和集数。
- 最近访问域名只保存在内存中，最多 600 条、最多回看 120 秒，用于把广告出现和近期请求关联起来。
- 因为需要代理流量和阻断广告请求，1.1.x 新申请了 `INTERNET` 权限。
